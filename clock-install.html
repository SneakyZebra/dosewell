Set up Android Clock

Install Dosewell Clock once

On your Android phone, download the companion and open the file. Android will ask you to confirm installation.

Download Dosewell Clock for Android

Return to the same browser, choose a dose or advance warning, and tap Set in Android Clock. On your first alarm, match the connection code and approve the connection. Future alarms use the same connection.

If a link stays inside another app, open Dosewell in Chrome on your Android phone. Open Clock → Alarm to check your first alarm. After changing a dose, edit or remove the old alarm in Clock.
